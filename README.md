# GoAkt Actor Example — Bank Account (Deposit & Withdraw)

This example demonstrates how to build a simple actor-based bank account
using [**GoAkt v4**](https://docs.goakt.dev/getting-started/quickstart).  
It shows how to:

- Create an `ActorSystem`
- Spawn an actor (`Account`)
- Send messages using `Ask`
- Handle multiple message types (`Deposit`, `Withdraw`, `Balance`, `InsufficientFunds`)
- Log results using GoAkt’s built‑in logger
